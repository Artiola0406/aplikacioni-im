# Aplikacion për Porosi Ushqimi

![Statusi](https://img.shields.io/badge/statusi-në%20zhvillim-orange)
![React Native](https://img.shields.io/badge/React%20Native-Expo-000020?logo=expo)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white)

Aplikacion mobil për porosi ushqimi nga një restorant lokal. Klienti e shfleton menynë, e bën porosinë dhe e ndjek statusin e saj deri në dorëzim, ndërsa restoranti i menaxhon porositë në një vend.

Projekt për lëndën **Zhvillimi i Aplikacioneve Mobile**, UMIB Mitrovicë.

## Qëllimi

Të zëvendësojmë porositjen me telefon dhe mesazhe me një aplikacion të thjeshtë, ku klienti di gjithmonë nëse porosia u pranua dhe kur do të vijë. Nevoja del nga tri biseda që bëmë me klientë dhe një punëtor restoranti (shih [BISEDAT.md](BISEDAT.md)).

## Teknologjitë

- **Gjuhët:** TypeScript, JavaScript
- **Aplikacioni mobil:** React Native me Expo dhe Expo Router
- **Backend dhe databaza:** Supabase (PostgreSQL, Auth, Realtime), në plan
- **Versionimi:** Git dhe GitHub
